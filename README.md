# media branch

Public image hosting for Elevating CHRIST and Nestoodle social posts (Instagram needs direct HTTPS image links).
Deployed separately on Vercel as `elevatingchrist-media`. This branch is unrelated to `main`.

Layout: `elevating-christ/<series>/<date>-<topic>/slide-N.jpg`

Nestoodle: `nestoodle/carousels/<date>-<topic>/slide-N.jpg` and `nestoodle/pinterest/<batch>/<pin>.jpg`,
rendered by `ops/content/nestoodle/render.mjs` in xredible/elevating-christ.
